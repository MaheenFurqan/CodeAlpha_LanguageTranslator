# Language Translator

A web-based language translation application built using Python, Flask, HTML, CSS, and JavaScript.

## Features

- Enter text to translate
- Select source language
- Select target language
- Translate text using an online translation API
- Display translated text
- Copy translated text
- Loading indicator while translating
- Error handling for failed requests
- Responsive and pastel-themed user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## Supported Languages

- English
- Urdu
- Spanish
- French
- German
